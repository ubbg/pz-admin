# CMD-001 — Die Befehlsfläche von Build 42

## User Story

> **Als** Administrator
> **möchte ich** die Serververwaltung aus der Anwendung heraus vollständig erledigen —
> SteamID-Whitelist, IP-Bann, Safehouses, Zombies, Weltgenerator —
> **damit** ich nicht für ein Drittel meiner Arbeit auf die Serverkonsole ausweichen muss,
> **ohne** dass mir dabei ein Befehl angeboten wird, den es nicht mehr gibt.

## Business Context

Build 42 kennt 58 Admin-Befehle (pzwiki, revidiert für 42.20.2). Die Anwendung deckt
davon ab:

* **30** mit Oberfläche und Go-Einstiegspunkt,
* **10** nur als Wort in der Autovervollständigung des Terminals
  (`banid`, `unbanid`, `invisible`, `noclip`, `voiceban`, `log`, `stats`,
  `releasesafehouse`, `reloadlua`, `help`),
* **19** gar nicht.

Dazu führt `frontend/src/components/Terminal.tsx:6-51` drei Befehle, die in der
B42-Liste nicht mehr stehen (`grantadmin`, `removeadmin`, `replay`) und einen
Schreibfehler (`godmod` statt `godmode`; der Go-Code sendet korrekt `godmode`).

Die 19 Fehlenden sind keine Randnotizen, sie decken ganze Aufgabenbereiche ab:

| Bereich | Befehle |
|---|---|
| Zugang | `addsteamid`, `removesteamid`, `setpassword` |
| Moderation | `banip`, `unbanip` |
| Safehouse | `addtosafehouse`, `kickfromsafehouse` |
| Welt | `removezombies`, `createhorde2`, `worldgen` |
| Spieler | `godmodplayer`, `invisibleplayer`, `teleportplayer` |
| Items | `addkey`, `removeitem` |
| Karte | `removemapsymbolsforuser` |
| Wartung | `reloadalllua` |
| WIP laut Wiki | `list`, `remove` |

`worldgen` ist dabei der interessanteste: Build 42 generiert die Welt stufenweise
(`start`, `recheck`, `stop`, `status`) — ein laufender Vorgang mit Zustand, kein
Einzelschuss.

## Technical Requirements

### Die Liste im Terminal ist Daten, kein Gedächtnis

`Terminal.tsx` führt heute eine handgepflegte Wortliste. Sie bleibt handgepflegt
(RCON gibt keine maschinenlesbare Befehlsliste her — `/help` liefert Fließtext), aber
sie wird **an einer Stelle** geführt, mit Build-Angabe im Kommentar, und enthält
nichts, was Build 42 nicht kennt (**PG-07**).

### Ein Befehl, ein Einstiegspunkt

Die Oberfläche baut **keine** Kommandozeilen. Für jeden Befehl, den ein Dialog oder
ein Knopf auslöst, gibt es genau eine exportierte Methode auf `*App`, die die
Zeichenkette zusammensetzt (**PG-08**). Das Terminal bleibt die einzige Ausnahme —
dort tippt die Nutzerin bewusst roh.

### Spielerbezogenes läuft über `RCONCommand`

Jeder neue Befehl, der auf einen oder mehrere Spieler wirkt, benutzt das bestehende
Muster mit `SuccessCheck`, `ErrorCheck`, `Notifications` und optional `UpdateFunc`
(**PG-09**). Ein PZ-Server antwortet auf Unsinn freundlich und ohne Fehler — wer nur
`err` prüft, meldet Erfolg, wo keiner war.

Für die Paare `godmode`/`godmodplayer`, `invisible`/`invisibleplayer` und
`teleport`/`teleportplayer` gilt: Der `…player`-Befehl wirkt auf *andere* und ist der,
den die Oberfläche braucht — die kurze Form zielt auf die eigene Figur der Konsole und
ist auf einem Server ohne eigenen Charakter sinnlos.

### Zurückfragen, wo es weh tut

`removezombies`, `worldgen stop`, `quit` und ein IP-Bann sind nicht zurücknehmbar oder
treffen mehr als eine Person. Sie bekommen einen Bestätigungsdialog, der **benennt,
was passiert** — nicht ein „Sind Sie sicher?" (**PG-10**).

### Übersetzt wird alles

Jeder neue Befehl bringt seine Beschriftungen, Dialogtexte und
Erfolgs-/Fehlermeldungen in **allen vier** Sprachkatalogen mit (**PG-11**). Go schickt
Schlüssel, keine Texte.

## Gate-Contract

| ID | Zusage | Prüfung |

| PG-07 | Die Terminal-Befehlsliste enthält keinen Befehl außerhalb der B42-Liste | Liste gegen `https://pzwiki.net/wiki/Admin_commands?action=raw` abgleichen; `grantadmin`, `removeadmin`, `replay` sind weg |
| PG-08 | Kein Kommandostring wird im Frontend zusammengesetzt | `grep -rn 'SendRconCommand(' frontend/src --include='*.tsx'` trifft nur `Terminal.tsx` |
| PG-09 | Spielerbezogene Befehle laufen über `RCONCommand` | `grep -n 'conn.Execute' rcon.go` trifft nur Watcher, `players_update` und `SendRconCommand` |

| PG-11 | Neue Schlüssel existieren in allen vier Katalogen | Schlüsselmengen-Diff aus `.claude/rules/i18n.md` über alle vier `common.json` |

## Data Model / Registry

Kein persistentes Modell. Zwei Zustände kommen hinzu:

* **`worldgen`** hat einen Fortschritt, den nur `worldgen status` kennt. Er wird
  gepollt wie die Spielerliste, mit derselben Zurückhaltung (nur solange der Tab offen
  ist), und **nicht** in der Konfiguration gespeichert.
* **SteamID-Whitelist** (`addsteamid`/`removesteamid`) hat keine Leseoperation über
  RCON. Die Anwendung führt deshalb keine Liste, sondern quittiert nur Erfolg — eine
  lokal geführte Liste wäre eine Behauptung.

## Dependencies

* Keine neue Bibliothek.
* Vier bis sechs neue Dialoge unter `frontend/src/components/Dialogs/`, dem
  bestehenden Muster folgend (`isOpen`/`onClose`/fachliche Props).
* Berührt `rcon.go`, `Terminal.tsx`, `Players.tsx`, `Tools.tsx` und alle vier
  `common.json`.

## Definition of Done

- [ ] Die 19 fehlenden Befehle haben einen Go-Einstiegspunkt
- [ ] Zugang, Moderation, Safehouse und Welt haben je eine Bedienfläche
- [ ] `worldgen` mit Status-Anzeige und den vier Unterbefehlen
- [ ] Terminal-Liste bereinigt und mit Build-Angabe versehen
- [ ] Bestätigungsdialoge für die nicht rücknehmbaren Befehle
- [ ] Alle Texte in vier Sprachen
- [ ] `../B42-Luecken.md` Abschnitt 3 abgehakt

## Anti-Patterns

* **Einen Befehl nur in die Autovervollständigung eintragen.** Genau so sind die
  heutigen zehn Halbfertigen entstanden.
* **`conn.Execute` direkt aus einer neuen Funktion.** Umgeht Erfolgsprüfung,
  Fortschritt und Benachrichtigung — und sieht im Code aus wie ein Sonderfall, der es
  nicht ist.
* **Die kurze Befehlsform für Fernwirkung nehmen.** `/godmode` ohne Namen zielt auf
  die Konsole selbst; auf einem Dedicated Server passiert damit nichts.
* **`removezombies` ohne Rückfrage an einen Knopf hängen.** Der Befehl räumt die
  geladene Welt leer, und niemand bekommt sie zurück.
* **Eine lokale SteamID-Liste führen.** RCON kann sie nicht lesen; was die Anwendung
  zeigt, wäre geraten.
